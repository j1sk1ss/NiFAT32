Use measured address-to-position coordinates

For a specific die, import its address ranges and physical rectangles as JSON. Coordinates apply to the memory array, with Y increasing downwards. Beam intersection exposes the whole tile; smaller ranges give finer analysis.

Format: {version:1, chipId, flashSize, source, unit, width, height, regions:[{start,size,x,y,width,height}]}. Offsets and sizes are bytes relative to flash start; rectangles must fit inside the array and address ranges must cover the flash exactly. Export a grid model for a complete example.

Intersection marks an exposed address range, not proven bit corruption. FAT and journal voting is per entry; intersecting several copies does not by itself prove recovery will fail.
